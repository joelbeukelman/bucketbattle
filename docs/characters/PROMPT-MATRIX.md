# Prompt Matrix: starter characters

_Generated by `pnpm prompts` from `prompt-kit.json`. Edit the JSON, not this file._

7 characters × 11 shots = **77 prompts** (3 images in the repo so far). Prompts use Midjourney V7 (`--v 7` with `--oref`), because V8.x dropped Omni Reference. For V8, use the run sheet's V8 mode: it moves the reference image to the start of the prompt with `--iw`.

## Run order (per character)
1. **Hero turnaround**: Front, 3/4, side and back of the same outfit, in the hard-faceted style. Used for modeling and image-to-3D. Once accepted, Claude crops a single front figure from it as this character's reference.
2. **A-pose** (2 shots: Front, Side): One pose per image, front and side, for rigging. References the single-figure front crop only (no group-shot style refs), so Midjourney returns one character instead of a lineup.
3. **Expressions** (6 shots: Neutral, Focused, Smug, Surprised, Triumphant, Defeated): One face per image, square close-ups. Six emotions for battle reactions.
4. **Instrument**: The drum alone in three views, modeled as a separate part. No character reference, so no person sneaks in.
5. **Map version**: Small, chunky version for the city map. Leads with the chibi proportions and uses only a light reference, so it keeps the outfit without copying the lanky body.

Style references: hero = REF-005, map = REF-004, plus the rap turnaround as a second hero style reference (it's the closest match to the faceted look).
