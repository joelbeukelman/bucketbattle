# Prompt Matrix: starter characters

_Generated by `pnpm prompts` from `prompt-kit.json`. Edit the JSON, not this file._

7 characters × 5 sheets = **35 prompts**. Syntax is Midjourney V7 (`--oref` / `--ow`); on V6 use `--cref` / `--cw` instead.

## Run order (per character)
1. **Hero turnaround**: Front, 3/4, side and back views. Used for modeling and AI image-to-3D. Run this first, then pick the best result: its image URL becomes this character's reference for the other sheets.
2. **A-pose**: Arms out at 45°, front and side. Used for rigging.
3. **Expressions**: Six faces for battle reactions.
4. **Instrument**: The drum on its own, front/side/top. Modeled as a separate part.
5. **Map version**: Chunky pixel-textured version for the city map. A light character reference keeps the outfit without copying the lanky proportions.

Style references (public URLs, already filled in): hero = REF-005 (https://raw.githubusercontent.com/joelbeukelman/bucketbattle/main/docs/references/images/ref-005-characters-battle-scale-drummers.jpg), map = REF-004 (https://raw.githubusercontent.com/joelbeukelman/bucketbattle/main/docs/references/images/ref-004-characters-map-scale.jpg).
