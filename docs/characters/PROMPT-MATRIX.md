# Prompt Matrix: starter characters

_Generated by `pnpm prompts` from `prompt-kit.json`. Edit the JSON, not this file._

7 characters × 5 sheets = **35 prompts** (6 images in the repo so far). Prompts use Midjourney V7 (`--v 7` with `--oref`), because V8.x dropped Omni Reference. For V8, use the run sheet's V8 mode: it moves the reference image to the start of the prompt with `--iw`.

## Run order (per character)
1. **Hero turnaround**: Front, 3/4, side and back of the same outfit. Used for modeling and image-to-3D. Once one is in the repo, it becomes this character's reference for the other sheets.
2. **A-pose**: Front and side in a rigging pose. Uses the turnaround as a strong reference so it's the same kid.
3. **Expressions**: Six close-ups for battle reactions, as a 3×2 grid.
4. **Instrument**: The drum alone in three views, modeled as a separate part. No character reference, so no person sneaks in.
5. **Map version**: Small, chunky version for the city map. Leads with the chibi proportions and uses only a light reference, so it keeps the outfit without copying the lanky body.

Style references: hero = REF-005, map = REF-004, plus the rap turnaround as a second hero style reference (it's the closest match to the faceted look).
